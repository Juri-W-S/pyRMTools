Here we show codes which we have used in our RM campaign simulations.

With ICCF_bias.py we investigated the simulation bias under the assumption of an ideal simulation when using different ICCF parameters.

With ICCF_trials.py we coarsly investigated the simulation using a RM observation parameter grid, to asses the code functionality and get an overview of the behaviour for different parameters.

check_RM_parameters.py is a tool which we have created, which allows the creator of a RM campaign to estimate how appropriate the observational parameters are for an AGN with a given luminosity and redshift.
